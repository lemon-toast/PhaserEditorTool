# 개발 순서

현재 상태: 2026-10-23 개발 버전 0.1 구현. 세부 검증·제한은 [구현 현황](IMPLEMENTATION_STATUS.md)을 따릅니다. 아래 체크는 각 항목 전체를 확인한 경우에만 완료 표시합니다.

## 현재 순차 작업 목록

추가 반영: 작업 저장·불러오기와 게임 데이터 Import·Export의 UI·입력 형식·저장 상태를 분리했습니다. 작업 저장은 현재 `.scene.json` 다운로드이며 경로를 기억하는 덮어쓰기 저장은 후속 범위입니다.

Phaser Editor의 장면 편집 흐름을 참고하되, 기존 게임 layout을 읽고 어댑터로 반영하는 현재 구조를 유지합니다. 아래 순서가 다음 작업의 우선순위이며, 뒤의 단계별 목록은 전체 요구사항 점검표입니다.

| 순서 | 작업 | 상태 | 완료 조건 |
| --- | --- | --- | --- |
| 1 | 객체별 게임 적용 범위와 현재 화면 내보내기 제한 표시 | 완료 | 내보내기와 같은 검증 사용, 제한·복구 상태 확인 |
| 2 | 다중 선택·묶음 이동·원점 정렬·격자 스냅 | 완료 | 부모·자식 중복 이동 방지, 부모 변환 대응, 한 번의 undo, Chrome 조작 확인 |
| 3 | 에셋 교체와 이미지 9-slice 상세 편집 | 완료 | 같은 종류의 에셋 선택·교체, Spine atlas 연결, 잘못된 입력 방지, undo·저장 왕복·누락 파일 처리. 게임 적용 미지원 표시 유지 |

| 7 | 재사용 그룹·프리팹 | 대기 | 원본·인스턴스·개별 수정 규약, stable ID와 버전 정책, 저장·재열기·undo. 게임 반영 범위 별도 명시 |
| 8 | 홀덤·맞고 어댑터 | 대기 | 기존 화면 읽기·편집부터 단계 적용. 실제 게임 반영은 별도 검증 |
| 9 | 데스크톱 배포·다중 창·운영체제 검수 | 대기 | Windows 패키징, 패널별 별도 OS 창·재도킹·복구, macOS 실기 확인 |

완료된 1~3번은 타입 검사, 단위 테스트, Chrome 테스트와 빌드 검증을 수행했습니다. 이는 전체 게임 적용·전체 편집 기능 완료를 의미하지 않습니다. 외곽선 정렬·균등 분배·범위 선택은 배치 편의 후속 목록으로 두고, 다음은 4번입니다.

- [ ] 에디터 내보내기와 게임 측 입력 검증에서 상대 경로·종류·누락 파일·경계 범위 확인
- [ ] 게임 초기 배치·resize 이후에도 변경 값이 유지되는 적용 순서 정의

### 작업 저장 후속 목록

- [ ] 작업 파일 경로 기억, 저장/다른 이름으로 저장, 저장 취소·실패 시 미저장 상태 보존
- [ ] 게임 패키지에 편집 문서가 없는 경우 Import 정책 정의

현재 완료: 작업/데이터 버튼 분리, 입력 형식 구분, Import 후 미저장 상태, Export·게임 적용 시 작업 저장 상태 유지. 파일 다운로드 저장과 경로 기반 덮어쓰기 저장은 구분합니다.

### 공통 진행 규칙

1. 착수 전 요구사항·구현 현황·관련 코드를 확인하고 세부 범위와 완료 조건을 문서화합니다.
2. 한 항목을 구현하고 변경에 맞는 typecheck·단위 테스트·Chrome 테스트·build를 수행합니다. 데스크톱 변경은 해당 테스트도 수행합니다.
3. 구현 결과와 제한을 구현 현황에 반영하고 이 표의 상태를 갱신한 뒤 다음 항목으로 이동합니다. 미검증 항목은 완료 처리하지 않습니다.
4. 에디터 문서 저장과 게임 반영을 구분합니다. 이웃 게임의 소스·에셋 변경이 필요한 작업은 먼저 이 저장소에서 규약과 어댑터·검증 준비를 마친 뒤, 명시적으로 승인된 범위에서 진행합니다.
5. 별도 OS 창·macOS 등 환경이 없는 검증은 미검증으로 남기고 가능한 독립 작업을 진행합니다.

## 검증 우선순위

자동 검증은 계층 순환 방지, active 전파, 변환 계산, undo/redo, 저장 왕복, 경로 루트 이탈 방지처럼 실패 영향이 큰 규칙에 집중합니다. 시각 결과는 실제 에셋을 사용한 브라우저 검증으로 확인합니다.

최초 사용자 확인 시나리오는 **이미지·Spine·파티클을 같은 그룹에 추가 → 부모 off/on → 애니메이션·입자 재생 → 자식 이동 → 저장·재열기**입니다.

최종 필수 시나리오는 **승자승 연출 선택 → 테스트 금액 입력 → 폭죽·팝업·머니 이동 재생 → Transform·연출 수정 → export → 실제 게임 import 및 재생 → 에디터 재import 비교**입니다. 데이터 연출과 등록 코드 연출 모두 확인합니다.

워크스페이스 검수는 **패널 분할·탭 묶기 → 별도 창 이동 → 연출 일시정지 상태에서 재도킹 → 저장·재시작 → 모니터 제거 후 복구**를 두 운영체제에서 수행합니다.
